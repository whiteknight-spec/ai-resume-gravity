# 📄 ResumeAI — AI-Powered Resume Analyzer & ATS Simulator

A modern, responsive web application designed to analyze resumes, simulate Applicant Tracking Systems (ATS), perform keyword matching, and execute bulk candidate ranking.

🔗 **Live Demo:** [https://ai-resume-gravity.vercel.app](https://ai-resume-gravity.vercel.app)

---

## ✨ Features

- 📑 **Bulk Resume Analysis:** Upload dozens of PDF resumes simultaneously and rank candidates instantly.
- 🎯 **ATS Simulator:** Paste a Job Description to evaluate candidate fit, keyword matching, and scoring metrics.
- 🔍 **In-Depth Candidate Review:** 
  - Overall ATS match score (/100)
  - Detailed strength evidence extracted directly from the resume
  - Actionable improvement feedback
  - Identified vs. Missing keyword taxonomy (Languages, Frameworks, Cloud, Databases)
- 📊 **Export Options:** Download complete ranking and candidate data directly as a `.csv` report.
- 🎨 **Modern Dark UI:** Responsive interface with custom animations and interactive score visualizations.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Modern CSS3 (CSS Variables, Flexbox/Grid), Vanilla JavaScript (ES6+)
- **Document Processing:** PDF.js (Client-side text extraction)
- **Deployment:** Vercel & GitHub Pages
